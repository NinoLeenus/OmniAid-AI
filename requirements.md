# Project Title
OmniAid AI – Omnichannel Volunteer Message Intelligence System (Reddit MVP)

# Problem Statement
Human rights NGOs and community organizations receive a high volume of distress messages across social platforms such as Reddit, WhatsApp, and Instagram. Volunteers struggle to:
- Read and understand every message
- Identify urgent cases
- Route cases to the right team
- Respond consistently and quickly

This leads to delays, volunteer burnout, and missed critical cases.

# Objective
To build an AI-powered system that ingests messages from social platforms (starting with Reddit), classifies and prioritizes them, and assists volunteers by generating structured summaries and draft responses.

# Scope (Phase 1)
- Reddit posts and DMs ingestion
- Case classification and urgency detection
- AI-assisted response drafting
- Volunteer review dashboard

# Target Users
- NGO volunteers
- Moderators
- Community support teams
- Human rights organizations

# Key Features
1. Message ingestion from Reddit
2. Case type classification
3. Urgency detection
4. Auto summarization
5. Draft response generation
6. Multilingual support
7. Volunteer review and approval
8. Analytics dashboard

# Functional Requirements
- Fetch Reddit messages and posts
- Analyze message content using AI
- Tag messages by category and priority
- Generate suggested responses
- Display results in a web dashboard

# Non-Functional Requirements
- Open-source stack
- Data privacy and anonymization
- Secure authentication
- Low-latency processing
- Scalable design

# Constraints
- AI does not auto-send replies
- Human-in-the-loop required
- No storage of personal identifiable data

# Success Metrics
- Reduced response time
- Improved volunteer productivity
- Accurate urgency detection
- Positive volunteer feedback
