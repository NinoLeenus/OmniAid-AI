# Telegram Message Streamer (Python)

Real-time Telegram bot that captures incoming messages and pushes them into a downstream processing pipeline **instantly** — no polling hacks needed.

Telegram's Bot API uses **long-polling** by default, which means your app is notified the moment a message arrives.

## What this app does
- Runs a Telegram bot that listens for all incoming messages.
- Supports text, photos, documents, voice, video, stickers, and commands.
- Optional **keyword filtering** — only process messages matching specific topics.
- Optional **user allowlist** — restrict to specific Telegram user IDs.
- Pushes each message into an async queue with multiple parallel workers.
- Downstream handler runs immediately for rapid action.

## Setup

### 1. Create a Telegram bot (takes 30 seconds)

1. Open Telegram and search for **@BotFather**.
2. Send `/newbot`.
3. Follow the prompts — choose a **name** and a **username** (must end in `bot`).
4. BotFather replies with your **bot token** — copy it.

### 2. Configure & run

```bash
cp .env.example .env
# paste your bot token into .env

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

Then **send a message to your bot** in Telegram — you'll see it processed in the console.

### 3. Optional: find your user ID

To restrict the bot to only your messages, send any message to the bot and check the logs — your `user_id` will appear. Add it to `TELEGRAM_ALLOWED_USER_IDS` in `.env`.

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | Bot token from @BotFather |
| `TELEGRAM_ALLOWED_USER_IDS` | ❌ | Comma-separated user IDs to accept (empty = all) |
| `TELEGRAM_TOPIC_KEYWORDS` | ❌ | Comma-separated keywords to filter messages (empty = all) |

## Replace downstream logic
Edit `DownstreamProcessor.handle_event()` in [app/downstream.py](app/downstream.py).

### Sending replies back to the user

The `DownstreamProcessor` is initialized with a `TelegramSender` — use it to reply:

```python
async def handle_event(self, event: TelegramEvent) -> None:
    # Process the incoming message
    logger.info(f"Got: {event.content}")
    
    # Send a reply
    if self.sender:
        reply_text = f"You said: {event.content}"
        await self.sender.send_message(event.chat_id, reply_text)
    
    # Or send a photo:
    # await self.sender.send_photo(event.chat_id, "https://example.com/pic.jpg")
    
    # Or a document:
    # await self.sender.send_document(event.chat_id, "https://example.com/file.pdf")
```

### Available methods
- `send_message(chat_id, text, parse_mode="Markdown")` — send text
- `send_photo(chat_id, photo_url, caption=None)` — send image
- `send_document(chat_id, doc_url, caption=None)` — send file

That's where you can:
- **Reply to messages** — use `self.sender.send_message()`
- **Call APIs** — fetch data and send results back
- **Trigger alerts** — send notifications to yourself
- **Database operations** — log or analyze the message
- **Publish events** — Kafka/SQS/Redis
- **Run ML models** — process text/images and reply
